Project Overview

This is a high-performance, globally distributed static website hosted entirely on Amazon Web Services. It demonstrates serverless architecture, low latency delivery via CDN caching, and secure communication over HTTPS.

AWS Architecture

🪣

Amazon S3

Stores static assets (HTML, CSS, JS, images) with high durability and security.

⚡

CloudFront CDN

Delivers cached content globally with ultra-low latency via edge locations.

🔒

AWS ACM (SSL)

Enables free HTTPS certificates for encrypted, secure communication.
